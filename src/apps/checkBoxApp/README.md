## とりあえず機能面で必要そうな事
 - チェックされたのを検知するstateが必要
 - チェックされていたら出現する、されていなかったら出現しない見にロジックみたいなのは必要

 - 項目も部分が全選択に見えて少し違うやつだ。
 - [x] どれかをチェックしたら"項目"も選択中になる。
   - これはstateで持つのではなく派生stateで持ったことによって解決
 - [x] "項目"をチェックすると全て選択中になる。
   - 全選択はOK

 - [x] count部分が可変でチェックされているチェックボックスの数の数字になる
  - checkのStateのlength見た。

 - [ ] 項目の途中のパーシャルの出現条件
   - 条件:１〜項目数-1
   - 何をするのか:項目の中身を横棒にする
